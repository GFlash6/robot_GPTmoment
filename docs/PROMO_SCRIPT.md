# GPTmoment for robot · 产品宣传片脚本

目标时长约 2 分钟。主线：提出机器人能力组合的问题 → 介绍 Agent 与 Skill → 穿插现场视频 → 展示任务反馈 → 展开跨场景与本地部署。

核心表达：**把机器人的每一种能力，编排成完成任务的行动。**

## 剪辑与命名规范

- 项目名称统一使用 `GPTmoment for robot`，保留这一大小写和空格；口播与封面采用同一名称。
- 片尾地址：`github.com/GFlash6/robot_GPTmoment`。
- 实拍旁注采用“当前任务 / 调用技能 / 执行反馈”三层结构，内容与对应镜头、记录一致。
- 场景组合使用流程示意动画；实拍保留完整动作过程，结果字幕对应可见证据。
