# 解耦 UI 验证

本轮实际执行结果：Python 全部 30 项测试、9 项子测试通过；TypeScript 检查和 Vite 生产构建通过；Chromium 的 4 项浏览器集成测试通过。Python 报告见 [pytest-ui.xml](validation/pytest-ui.xml)。

观察服务测试直接读取核心产生的真实 SQLite 账本，检查只读连接拒绝写入、查询前后数据库内容不变、缺失目录不会被创建、真实分块复制占用与取消释放、HTTP 写请求拒绝、分页和过滤、纳秒整数保真，以及导入观察服务不加载核心或 DBOS。

浏览器使用 `ui/tests-data.py` 创建的独立 `.runtime/ui-validation` 账本：实际归档设计文档并校验；实际读取缺失文件产生失败，随后执行配置中的文件归档 fallback；实际分块复制后请求暂停并检查停止返回。记忆条目引用实际资产。未生成 AI 回复、机器人状态或相机画面。

浏览器验证覆盖任务图与节点结果、执行尝试、事件、资产证据跳转、资源空闲记录、模型无记录状态、浏览器真实断网后的数据保留与过期提示、恢复连接，以及 768px 宽度的可用性。没有拦截请求并注入模拟响应。

截图由浏览器读取上述实际记录后保存：[总览](validation/ui-overview.png)、[任务图](validation/ui-task.png)。截图仅记录验证时刻，实时数据以 API 返回为准。

仍未验证真实模型成功路径和机器人动作；本轮界面检查不改变这一结论。未提供任务编辑/控制、3D 点云地图预览、传感器视频播放、机器人心跳、远程认证或超大账本性能验收。它们记录在 OPEN_QUESTIONS.md。
