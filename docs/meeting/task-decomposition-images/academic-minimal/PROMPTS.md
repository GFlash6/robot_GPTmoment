## 05 反馈驱动的计划修订
标题“反馈闭环：何时触发重新分解”
绘制正式学术泳道图，四条水平泳道，左侧标签“导航/感知”“执行编排”“上下文构建”“任务分解”。流程只包含下列顺序与箭头：
导航泳道左“遇阻，局部绕行”→导航泳道中“持续阻塞，返回原因”；
从“持续阻塞，返回原因”向下执行泳道“确认原执行已停止”；
再向下上下文泳道“更新失败、位姿、地图版本”；
再向下任务分解泳道“调整策略”→同泳道右“修订候选 DAG”；
从修订候选DAG向上执行泳道右“校验并派发”；
再向上导航泳道右“执行新目标”。
严禁“持续阻塞”直接连“执行新目标”，新目标只能由“校验并派发”指向。
下方三项并列短注“正常进度：不触发重规划”“地图变化：重验目标引用”“定位失效：先恢复有效状态”。
底部结论“结果未知或未确认停止：查询原执行，保留资源，不直接重发。”
页脚“闭环目标设计｜真实导航反馈待接入”，页码“05 / 06”。
